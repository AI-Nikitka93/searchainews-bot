- **Что осталось непроверенным:** live Telegram command scope was not mutated because changing Telegram bot settings requires explicit approval. Live default scope remains empty until `python scripts/set_bot_commands.py` is run with the real token.

### BOT-003 High - Inline mode remains disabled for a news/search bot
- **Status:** open
- **Evidence:** MEASURED `getMe.supports_inline_queries=false`; SUPPORTED_BY_CODE no `inlineQuery` / `answerInlineQuery` handlers.
- **Impact:** users cannot call `@impactpulse_bot query` from other chats to share/search AI news natively.

### BOT-004 Medium - No Main Mini App / WebApp surface
- **Status:** open
- **Evidence:** MEASURED `getMe.has_main_web_app=false`, `getChatMenuButton.type=commands`; SUPPORTED_BY_CODE no `Telegram.WebApp` / `web_app` / `initData`.
- **Impact:** acceptable for a simple content bot, but prevents richer settings/history/search surface inside Telegram.

### BOT-005 Medium - Notification consent is effectively default-on
- **Status:** open
- **Evidence:** SUPPORTED_BY_CODE `cf_worker/src/services/users.ts:27-37` defaults missing users to `is_subscribed=true`; new role/language rows do not force explicit opt-in.
- **Impact:** users can unsubscribe, but the first consent moment is weak for a notification product.

### BOT-006 Medium - Deep-link payload and attribution are absent
- **Status:** open
- **Evidence:** OBSERVED deep-link launch page opens; SUPPORTED_BY_CODE `/start` handler does not parse payload; no referral/campaign fields in schema.
- **Impact:** no campaign attribution, role presets or referral tracking from Telegram deep links.

### BOT-007 Medium - KPI layer still cannot measure retention or conversion
- **Status:** open

### BOT-008 Medium - Telegram-specific automated tests are still shallow
- **Status:** open
- **Evidence:** SUPPORTED_BY_CODE scripts exist for diagnose/send/set commands; no isolated dialog test harness, no callback regression tests, no inline/WebApp tests.
- **Impact:** command/menu regressions are likely to be caught late by manual QA or live probes.

### BOT-009 Medium - Default command scope was empty; local repair is prepared
